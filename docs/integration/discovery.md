# Auto-Discovery Integration

**Status:** ⚪ PLANNED

## Purpose
To automatically scan subnets and auto-populate Pipeline 1 (Camera Registry) with newly installed cameras, rather than relying exclusively on manual JSON/CSV imports.

## Planned Implementation
The system intends to support network scanning (e.g., WS-Discovery for ONVIF, or proprietary broadcasts for Sentinel cameras). 
This feature is currently documented in the PRD but has not yet been developed into the backend.
